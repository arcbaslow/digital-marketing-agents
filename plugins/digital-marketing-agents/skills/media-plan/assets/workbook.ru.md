# Книга медиаплана

Используйте следующий порядок вкладок и адреса ячеек. Замените заполнители в угловых скобках согласованными значениями. Формулы с английскими функциями и запятыми даны как исходный вариант; запишите и прочитайте одну тестовую формулу перед заполнением диапазонов. Переводите значения статусов вместе с формулами и списками проверки. Даты храните как даты, а не похожий на даты текст; коды строк храните как текст.

## 1. Сводка

| Ячейка/область | Заголовок | Значение или формула |
| --- | --- | --- |
| B2 | Период | <даты начала и окончания> |
| B3 | Валюта | ='Допущения'!B6 |
| B4 | Медиабюджет нетто | =SUM('План'!J2:J) |
| B5 | Агентское вознаграждение | =SUM('План'!M2:M) |
| B6 | НДС | =SUM('План'!N2:N) |
| B7 | Бюджет брутто | =SUM('План'!O2:O) |
| B8 | Бюджет брутто, USD | =SUM('План'!Q2:Q) |
| B9 | Дата допущений | ='Допущения'!B5 |
| D2:E6 | Версия / Статус / Ответственный / Кто согласует / Дата согласования | <версия / статус / роли / дата> |
| D8:E9 | Ограничения прогноза / Прочие расходы | <неопределённость, включённые и исключённые расходы> |
| A12:C<последняя строка каналов> | Канал / Бюджет нетто / Бюджет брутто | Список каналов; =SUMIF('План'!E$2:E,A13,'План'!J$2:J); =SUMIF('План'!E$2:E,A13,'План'!O$2:O) в первой строке данных |
| E12:G<последняя строка целей> | Показатель / Цель / База и ответственный | <согласованные цели, период, единица, прогноз или обязательство, владелец источника> |
| A<начало месяцев>:C<конец месяцев> | Месяц / Бюджет нетто / Бюджет брутто | Даты месяцев; SUMIF по столбцу B вкладки План для J и O |
| E<начало легенды>:F<конец легенды> | Роль ячейки / Значение | Синий: ввод, чёрный: формула внутри вкладки, зелёный: ссылка на другую вкладку; светлая заливка ввода |

Уместите сводку на одном экране. Деньги показывайте целыми значениями, доли с одним десятичным знаком, даты в едином формате. В заголовках денежных сумм укажите <основную валюту>; столбец USD обозначьте отдельно. Укажите, что прогноз не гарантирует результат, и сформулируйте решение для согласования.

## 2. План

Строка 1 содержит заголовки без объединения ячеек. Данные начинаются со строки 2. Копируйте формулы вниз; каждая строка ссылается на свою строку набора допущений. Строка 14 вкладки Допущения ниже является первой строкой бенчмарков, а не общим бенчмарком для всех каналов. Допустимые цели: Результат или Охват. Модели закупки: CPM или CPC; для охвата используется CPM.

| Столбец | Заголовок | Ввод или формула строки 2 |
| --- | --- | --- |
| A | Код строки | <постоянный текстовый ключ> |
| B | Месяц | <первое число месяца> |
| C | Дата начала | <дата внутри месяца> |
| D | Дата окончания | <дата внутри месяца, не раньше начала> |
| E | Канал | <канал> |
| F | Продукт | <продукт> |
| G | Формат | <формат> |
| H | Цель | <Результат или Охват> |
| I | Модель закупки | <CPM или CPC> |
| J | Бюджет нетто, <основная валюта> | <согласованный ввод медиабюджета нетто> |
| K | Ставка НДС | ='Допущения'!$B$2 |
| L | Ставка агентского вознаграждения | ='Допущения'!$B$3 |
| M | Агентское вознаграждение, <основная валюта> | =IF(A2="","",J2*L2) |
| N | НДС, <основная валюта> | =IF(A2="","",(J2+M2)*K2) |
| O | Бюджет брутто, <основная валюта> | =IF(A2="","",J2*(1+K2)*(1+L2)) |
| P | Курс, <основная валюта>/USD | ='Допущения'!$B$4 |
| Q | Бюджет брутто, USD | =IF(A2="","",IF(P2=0,0,O2/P2)) |
| R | Плановый CPM, <основная валюта> | ='Допущения'!E14 |
| S | Плановый CPC, <основная валюта> | ='Допущения'!F14 |
| T | Плановый CTR | =IF(H2="Охват","",'Допущения'!G14) |
| U | Показы | =IF(A2="","",IF(I2="CPC",IF(T2=0,0,V2/T2),IF(R2=0,0,J2/R2*1000))) |
| V | Клики | =IF(A2="","",IF(H2="Охват","",IF(I2="CPC",IF(S2=0,0,J2/S2),U2*T2))) |
| W | Конверсия в заявку | =IF(H2="Охват","",'Допущения'!H14) |
| X | Заявки | =IF(A2="","",IF(H2="Охват","",V2*W2)) |
| Y | CPL, <основная валюта> нетто | =IF(A2="","",IF(H2="Охват","",IF(X2=0,0,J2/X2))) |
| Z | Конверсия в продажу | =IF(H2="Охват","",'Допущения'!I14) |
| AA | Выдано или продано | =IF(A2="","",IF(H2="Охват","",X2*Z2)) |
| AB | CPS, <основная валюта> нетто | =IF(A2="","",IF(H2="Охват","",IF(AA2=0,0,J2/AA2))) |
| AC | Охват, человек | =IF(A2="","",IF(H2="Охват",IF(AD2=0,0,U2/AD2),"")) |
| AD | Частота | =IF(H2="Охват",'Допущения'!J14,"") |
| AE | Набор допущений | ='Допущения'!A14 |
| AF | Готовность | Используйте формулу ниже, переводя при необходимости значения статусов согласованно |

```gs
=IF(A2="","",IF(OR(J2="",K2="",L2="",P2=0,AE2="",'Допущения'!$B$2="",'Допущения'!$B$3="",'Допущения'!$B$4="",'Допущения'!N14<>"Согласовано",AND(I2="CPM",R2=0),AND(I2="CPC",OR(S2=0,T2=0)),AND(H2="Охват",AD2=0),AND(H2="Результат",COUNTBLANK('Допущения'!G14:I14)>0)),"Нет допущений","Готово"))
```

Бюджетный блок занимает J:Q, блок рекламных показателей R:V, бизнес-показатели W:AB, показатели охвата AC:AD. Не скрывайте деление через IFERROR. Нули от защиты деления не являются готовым прогнозом, пока AF не имеет статус Готово. Покажите неполные строки в Сводке; не отправляйте прогноз как завершённый, пока хотя бы одна обязательная строка не готова.

Для итогов используйте SUM по складываемым столбцам. Общий CTR результативных кампаний считайте как SUM(V) / SUM(U) только по строкам с целью Результат, с защитой IF. Общий CPL считайте как нетто результативных кампаний / сумма заявок, CPS как нетто результативных кампаний / сумма продаж, с защитой знаменателей. Не суммируйте AC между каналами и не усредняйте Y/AB. Итоговые строки размещайте вне диапазона фильтра данных или на Сводке.

## 3. Флоучарт

| Столбец/строка | Заголовок | Значение или формула |
| --- | --- | --- |
| A:E, начиная со строки 2 | Код строки / Месяц / Начало / Конец / Бюджет нетто | Ссылки по ключам на A, B, C, D, J вкладки План |
| F1 и далее | Неделя с <дата понедельника> | Настоящие даты понедельников; следующий заголовок =F1+7 |
| F2 и далее | Недельные расходы нетто | Формула ниже для равномерного дневного распределения |
| После последней недели | Распределено / Разница | =SUM(F2:<ячейка последней недели>); =<ячейка распределённой суммы>-E2 |
| Под данными | Недельный итог / Общая разница | SUM каждой недели; сумма разниц строк |
| Под итогами | События | <старт / смена креатива / окончание, подробности в примечаниях> |

```gs
=IF($A2="","",IF($D2-$C2+1=0,0,$E2*MAX(0,MIN($D2,F$1+6)-MAX($C2,F$1)+1)/($D2-$C2+1)))
```

Проверьте D >= C до расчёта. Включите все пересекающиеся недели, в том числе неполные. Для размещения с паузами или пиками замените равномерное дневное распределение согласованными недельными значениями, сохранив проверки итогов. Заливайте ячейки с расходами > 0; шкала одного оттенка может показывать интенсивность. Разницы должны укладываться в допуск из Допущения B9.

## 5. План-факт

Сохраните A:AF с теми же заголовками и плановыми значениями, что в Плане. Заполняйте A:B из основного списка ключей. Для C:AF используйте поиск по ключу, а не ссылки на положение строки, которые ломаются при сортировке. Пример для J2, копируемый по столбцам с заменой возвращаемого столбца:

```gs
=IF($A2="","",IF(COUNTIFS('План'!$A$2:$A,$A2,'План'!$B$2:$B,$B2)=0,"Нет ключа в плане",INDEX(FILTER('План'!J$2:J,'План'!$A$2:$A=$A2,'План'!$B$2:$B=$B2),1)))
```

Проверьте уникальность пар A+B до поиска. Добавьте следующие столбцы; фактические значения берите из сверенной выгрузки с тем же ключом. Отмечайте ожидаемые данные статусом, а не незаметным нулём. Фактические стоимостные показатели ниже используют медиабюджет нетто.

| Столбец | Заголовок | Ввод или формула строки 2 |
| --- | --- | --- |
| AG | Факт нетто, <основная валюта> | <сверенный факт> |
| AH | Факт вознаграждения, <основная валюта> | <сверенное вознаграждение> |
| AI | Факт НДС, <основная валюта> | <сверенный НДС> |
| AJ | Факт брутто, <основная валюта> | =IF(AX2<>"Сверено","",SUM(AG2:AI2)) |
| AK | Факт показов | <факт> |
| AL | Факт кликов | <факт или пусто, если неприменимо> |
| AM | Факт заявок | <факт или пусто, если неприменимо> |
| AN | Факт выдано или продано | <факт или пусто, если неприменимо> |
| AO | Факт CTR | =IF(AX2<>"Сверено","",IF(H2="Охват","",IF(AK2=0,0,AL2/AK2))) |
| AP | Факт CPL, <основная валюта> нетто | =IF(AX2<>"Сверено","",IF(H2="Охват","",IF(AM2=0,0,AG2/AM2))) |
| AQ | Факт CPS, <основная валюта> нетто | =IF(AX2<>"Сверено","",IF(H2="Охват","",IF(AN2=0,0,AG2/AN2))) |
| AR | Отклонение нетто, <основная валюта> | =IF(AX2<>"Сверено","",AG2-J2) |
| AS | Отклонение нетто, % | =IF(AX2<>"Сверено","",IF(J2=0,0,(AG2-J2)/J2)) |
| AT | Процент использования, нетто | =IF(AX2<>"Сверено","",IF(J2=0,0,AG2/J2)) |
| AU | Отклонение заявок, количество | =IF(AX2<>"Сверено","",IF(H2="Охват","",AM2-X2)) |
| AV | Отклонение заявок, % | =IF(AX2<>"Сверено","",IF(H2="Охват","",IF(X2=0,0,(AM2-X2)/X2))) |
| AW | Статус расходования | =IF(AX2<>"Сверено","Ожидается факт",IF(AND(J2=0,AG2<>0),"Внеплановые расходы","Сравнить с согласованными порогами")) |
| AX | Статус факта | <Ожидается или Сверено> |
| AY | Комментарий | <объяснение в одну строку> |
| AZ | Причина | <подтверждена / предполагается / неизвестна и основание> |
| BA | Действие | <действие, ответственный и дата> |

Добавьте пары отклонений продаж или других показателей, если от них зависит согласование; сохраните тот же принцип абсолютного и относительного расчёта. Расходы при нулевом плане отмечаются в AW, даже если защита в AS/AT возвращает ноль. Храните пороги в Допущениях, если нужны автоматические диапазоны расходования.

Столбцы: Дата | Кто | Что изменилось | Почему | Кто согласовал | Изменение нетто/брутто | Версия/статус. Записывайте согласование и каждое последующее изменение. Согласованный план и новый прогноз должны различаться; не переписывайте запись о согласовании.

## Месячные вкладки и дополнительные источники

Добавьте `План <ГГГГ-ММ>` для каждого месяца, сохранив A:AF Плана. В AH1 укажите дату месяца, в строке 1 заголовки из Плана. В A2 используйте следующую формулу представления, сохранив месяц как настоящую дату:

```gs
=IF(COUNTIF('План'!B2:B,$AH$1)=0,"Нет плановых строк",FILTER('План'!A2:AF,'План'!B2:B=$AH$1))
```

Защитите представление от ручных правок. Необязательные вкладки `Выгрузка <источник период>` сохраняют выгрузки без изменений с примечаниями об источнике и обновлении. Необязательный Новый прогноз использует те же ключи и столбцы и указывает версию согласованного плана для сравнения. Сводка всегда суммирует План, а не его копии по месяцам.
